# Patrik Beichner Portfolio

A simple personal portfolio website built with HTML, CSS, and JavaScript. The site presents a clean, modern landing experience with a custom navigation, animated background effects, and pages for projects and contact information.

## Overview

This project is a static website for showcasing a developer portfolio. It includes:

- A home page with a short introduction
- A projects page with links to featured work
- A contact page
- A visually styled layout with custom fonts and animated star-like effects

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- [index.html](index.html) — home page
- [projects.html](projects.html) — projects showcase page
- [contact.html](contact.html) — contact page
- [css/styles.css](css/styles.css) — styling for the site


## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder in your browser.
3. Launch [index.html](index.html) directly, or use a local preview tool such as Live Server in VS Code.

### Local Preview

Because this is a static website, no build step is required. You can simply open [index.html](index.html) in a browser or serve the folder locally.

## Features

- Responsive navigation menu
- Custom visual styling with dark background and light text
- Animated background effects on the main page
- Links to projects and contact information
